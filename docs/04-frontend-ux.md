# Frontend UX

The web application is a Next.js 16 App Router PWA using React 19, Tailwind CSS v4, and shadcn/ui-style components.

## Main surfaces

- Chat-first workflow with streaming AI responses and tool result parts.
- Responsive dashboard, settings, onboarding, alerts, journal, portfolio, and chart views.
- Auth pages for login, owner-first registration, password reset, and email verification.

## UX requirements

User-facing changes should preserve keyboard access, responsive layouts, visible loading/error states, reduced-motion support, and the existing semantic design tokens. Keep secrets and server-only configuration out of client components.
