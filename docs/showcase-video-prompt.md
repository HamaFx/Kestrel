# Kestrel — AI Showcase Video · Ready-to-Use Scene Prompts

> **Purpose:** One copy-paste prompt per scene. No screenshots needed, nothing to assemble before generating.
> **Tool:** Veo 3.1 (recommended) or Kling 3.0 — both take plain-English prompts.
> **Settings per scene:** 16:9 · 8 seconds · 1080p or higher. Roll each scene 2–3 times and keep the best take.
> **Total:** 11 scenes ≈ 88 seconds.

---

## How to use (2 minutes of setup, then paste prompts)

1. Open your AI video tool and set **16:9 · 8s · 1080p**.
2. Paste **Scene 0** below → generate. Repeat for every scene (2–3 takes each, pick the best).
3. Put the clips in order in CapCut (free): Scene 0 → 1 → 2 → … → 9. Hard cuts only.
4. Add the voiceover (Part 2) and captions in orange (Part 3). Done.

> **Note on the UI:** without screenshots, the app interface is AI-imagined — that's fine at cinematic distance. The prompts deliberately keep visible text short and in the background so garbled micro-text is never noticeable. If you later want pixel-perfect UI, run `pnpm dev:local`, screenshot the app, and feed those images as Veo "Ingredients" — the prompts still work.

## Part 3 — Post-production (10 minutes)

1. **Stitch:** CapCut (free) — drop the 11 clips in order, hard cuts.
2. **Voiceover:** generate Part 2 lines, one per clip, timestamps aligned.
3. **Music:** minimal dark-synth pulse at 100–110 BPM (CapCut stock or Suno); swell in the last 20 seconds.
4. **Captions:** burn in short orange `#F56E0F` monospace keywords over key moments — "33 TOOLS", "RISK VETO", "BYOK", "10 PROVIDERS" — using CapCut auto-captions.
5. **Vertical version (optional):** set the timeline to 9:16 and re-center; reuse scenes 0, 3, 4, 5, 6, 7, 9 (same prompts, same tool setting changed to 9:16).
