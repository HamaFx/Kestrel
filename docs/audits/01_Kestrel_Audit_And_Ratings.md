# Kestrel Maintainability, Reliability & Vibe-Coding Audit Scorecard

> **Scope:** Full static, architectural, operational, and AI-maintainability ("vibe-coding") audit of `Kestrel` (`v0.1.0`, commit `314e0746`, 2,721 archive entries, **2,052 code files**, **311,530 lines of code** across `apps/web`, `apps/worker`, 7 core packages, 4 plugins, `loadtest`, `infra`, and `scripts`).
> **Standards Referenced:** ISO/IEC 25010 Software Product Quality Model (Modularity, Reusability, Analyzability, Modifiability, Testability), Vibe-Coding Context-Window Hygiene (<300 LOC/file rule), and Production Reliability Engineering ("Errors as Values", Idempotency, Zero-Side-Effect Imports).

## 1. Locked Architectural & Product Decisions (Updated)

Based on your confirmation, the entire maintainability roadmap is governed by these **6 locked decisions**:

## 2. Executive Scorecard

Kestrel is an exceptionally ambitious, institutional-grade monorepo with world-class guardrails already in place—including blocking Knip dead-code checks, PostgreSQL Row-Level Security (RLS) via `AsyncLocalStorage`, automated route security classification (`check-route-security.mjs`), env contract verification (`check-env-contract.mjs`), and a 1-click Plugin SDK (`@kestrel/plugin-sdk`).

However, rapid iterative AI-assisted development ("vibe coding") across multiple architectural eras has left behind **75 oversized files (>500 LOC)**, **legacy billing/portfolio/bot subsystems (~13,000+ LOC of removable code)**, **86 flat root files in core directories**, and **108 silent `catch {}` blocks**.

## 3. Deep-Dive Findings by Category

### 3.1 Removable Dead-Weight Subsystems (~13,300+ LOC to Delete)

Executing **DEC-01**, **DEC-02**, and **DEC-03** immediately removes over **13,300 lines of code** that no longer align with Kestrel's BYOK + Plugin Store product architecture:

1. **External Billing, Subscriptions & Credit Wallets (`DEC-01` — ~7,500 LOC to remove):**
   - **What gets removed:**
     - Payment services & clients: `apps/web/src/lib/services/stripe-billing.ts` (645L), `apps/web/src/lib/stripe.ts` (114L), `apps/web/src/lib/services/gammal-billing.ts` (585L), `apps/web/src/lib/gammal.ts` (225L), `apps/web/src/lib/nowpayments.ts` (178L), `apps/web/src/lib/billing-gate.ts` (168L), `apps/web/gammal-tech.html` (32L).
     - API routes & crons: `/api/billing/*` (6 routes, 1,272L), `/api/admin/billing/*` (3 routes, 215L), `/api/cron/billing-dlq` (54L), `/api/cron/billing-reconcile` (113L), `infra/cron-vm/units/kestrel-billing-dlq.*`.
     - UI components & pages: `apps/web/src/app/(app)/settings/billing/**` (11 files, 1,359L), `apps/web/src/app/(app)/admin/_components/admin-billing.tsx` (207L).
     - Database queries, schemas & seeds: `packages/db/src/queries/credit-wallet.ts` (919L), `billing-extras.ts` (374L), `billing.ts` (183L), `billing-events.ts` (125L), `billing-customers.ts` (92L), `packages/db/src/schema/billing*.ts`, `credit-*.ts`, `packages/db/scripts/seed-billing.ts`, `seed-plans.ts`, `packages/ai/src/credits.ts` (153L), `packages/shared/src/billing/*` (127L), and obsolete billing plan docs (`docs/plans/*billing*`, `docs/plans/*gammal*`, `docs/plans/*qi*`).

3. **Legacy Telegram & Deprecated `@kestrel/ai/mastra` Barrel (`DEC-02` — ~3,700 LOC):**
   - Verify cleanup of `packages/ai/src/bot/`, `packages/ai/src/telegram/`, `/api/bot/*`, `/api/telegram/webhook`, and migrate any remaining callers of `@kestrel/ai/mastra` (28 occurrences in snapshot `314e0746`) to `@kestrel/ai/mastra-v2` so `packages/ai/src/mastra/index.ts` (503L) is completely deleted.
